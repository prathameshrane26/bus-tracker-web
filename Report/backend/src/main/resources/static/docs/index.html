5. Real-Time WebSocket & STOMP Protocol

                WebSocket API
            


            

                

                    

                        WS
                        /ws-bus-tracker
                        SockJS & STOMP Real-Time Gateway
                    

                    ▼
                

                

                    
The backend provides a full duplex WebSocket interface using STOMP over SockJS at /ws-bus-tracker. Drivers publish GPS updates via STOMP, and passengers/apps subscribe to topic channels.


                    

                        
Broadcast Topics (Subscriptions)

                        

                            
                                

                                    Topic Destination
                                    Description
                                    Payload Type
                                

                            
                            
                                

                                    /topic/bus-locations
                                    All live bus GPS updates broadcasted system-wide
                                    BusLocationUpdate
                                

                                

                                    /topic/bus/{busId}
                                    Targeted updates for a specific bus (e.g. /topic/bus/GA-03-X-1001)
                                    BusLocationUpdate
                                

                                

                                    /topic/active-buses
                                    Set of currently active bus IDs
                                    Set<String>
                                

                                

                                    /topic/bus-stopped
                                    Fired when a driver stops location sharing
                                    {"busId": "...", "status": "STOPPED"}
                                

                                

                                    /topic/schedule-added
                                    Fired when admin adds or updates a schedule
                                    BusSchedule
                                

                                

                                    /topic/schedule-deleted
                                    Fired when admin deletes a schedule
                                    {"scheduleId": "...", "busId": "..."}
